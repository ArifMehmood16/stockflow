## Deliver

Implement SSE with initial snapshot, generation/sequence, command completed/failed events and bounded replay. Use cursor expiry resync, heartbeats and slow-consumer backpressure. Metric objects carry mode/source/unit/window/missing/sample metadata. Tokens must not appear in URLs, logs or exported events; choose same-origin/session transport before frontend integration.

## First evidence or failing behavior

Reconnect resumes without duplicates; an expired cursor gets a fresh snapshot, not silently incomplete history. Reset invalidates old generation. A slow client cannot grow memory without bound or block the engine; dropped optional traces are disclosed.

## Acceptance criteria

Existing event/schema limits are enforced and integration-tested. Critical command outcomes remain recoverable from snapshots/status. Client-visible readiness/topology changes follow observed completion.

## Verification

## Handoff evidence
