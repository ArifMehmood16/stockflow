## First evidence or failing behavior

## Acceptance criteria

UI node lifecycle follows actual process/readiness state. State lost with one JVM does not erase durable reservations. Native and Docker lifecycle have explicit bounded cleanup behavior.

Use the exact current target names; add a target only where this card introduces it. Record the command and observed result. Never count unavailable infrastructure as a pass.
