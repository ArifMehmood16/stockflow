## Decisions and limitations

The owner prioritized a simple, working native backend over CI/CD and Docker polish. No CI workflow was added. Native API selects one run per process; it has no load-generator or measured throughput claim. The 200,000-row history caps have no cleanup worker yet. Docker's isolated bootstrap path is not proven equivalent to the run-owned native path. A07 and Phase 1 exit criteria remain partial until required Docker evidence is available or the owner explicitly revises that gate.
